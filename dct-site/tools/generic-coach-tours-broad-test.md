# Generic Coach Tours — Broad Test

This is a 56-keyword destination test for the paused campaign `DCT | Search | Canada | Operators | 2026`.

## Keywords

Every row is broad match. Each approved destination is paired with both `coach tours` and `bus tours`; for example:

- `England coach tours` — Broad
- `England bus tours` — Broad
- `Spain coach tours` — Broad
- `Spain bus tours` — Broad

Use the existing generic RSA and homepage URL. If adding a fresh ad group, call it `DCT | Generic Coach Tours | Broad Test` and pause the old `DCT | Generic Coach Tours | HOLD` group so the old exact/phrase terms do not run alongside this test.

The ready-to-upload keyword rows are in `generic-coach-tours-broad-test.csv`. The destination set combines the top destinations in Navi’s 9 September reply with Kiran’s explicit no-negative exceptions. Canada, the USA and Morocco are intentionally absent.

## Operating note

The campaign is currently using Maximize Conversions and is budgeted at C$65/day. Broad match is a sensible controlled test with that bidding strategy, but review Search terms daily for the first week and add negatives for irrelevant bus/coach intent before increasing spend. Do not replace the operator-focused ad groups with this test.
